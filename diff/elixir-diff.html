Comparing Elixir code

Elixir's pattern matching and pipelines pack a lot of logic into compact expressions, so a diff is the fastest way to see which clause or pipe stage changed. Paste two versions and the changed tokens are highlighted precisely.

Elixir-specific things to watch

  • Pattern-match clauses: a changed function head can route inputs completely differently.
  • Pipe order (|>) — reordering stages changes behaviour even when all stages look familiar.
  • Atoms vs strings and map/keyword-list syntax.

Elixir has mix format, so formatting both sides keeps the diff focused on logic. It runs entirely in your browser.

Elixir changes that are bigger than they look

Elixir's expressiveness means small textual edits can carry large behavioural weight. Pattern matches in function heads are the clearest example: adding or reordering a clause changes which implementation runs for a given input, and because Elixir tries clauses top to bottom, a reordering that looks like pure formatting in a diff can change the result.

Watch for with chains gaining or losing a step, and for changes to the else block that handles their failures — a common source of errors that silently change shape. Supervision-tree edits deserve the same care: a changed restart strategy (:one_for_one versus :rest_for_one) is one atom, and it changes what happens to sibling processes when one crashes.

Run mix format on both sides first. Elixir's formatter is standard across the ecosystem, so normalising removes whitespace noise and leaves only semantic differences to read.

Common questions

Does it handle multiple function clauses with pattern matching?

Yes — each clause is just a line (or block) of text, so an added or reordered pattern-matched clause shows up as an insertion or move, same as any other language.

Does it work for LiveView .heex templates?

Yes, .heex is text like any other source file, so template markup changes diff the same way as .ex module changes.

Is my Elixir code uploaded?

No. The comparison runs entirely in your browser, so private Phoenix apps stay on your device.
