Common questions

What config formats does it work with?

Any line-based key-value or bracketed-section format — INI, .conf, .cfg, Windows-style config, systemd unit files and similar all diff cleanly as text.

Can it ignore comment-line changes?

Not automatically — a changed comment shows as a changed line, which is usually useful when reviewing what someone actually edited.

Is my config file uploaded?

No — the comparison happens entirely in your browser, so internal service names, ports and credentials in the file never leave your device.
