How to compare two files with Diffhero

  1. Paste or type the original version into the left box (or drag a file onto it).
  2. Paste the changed version into the right box.
  3. See the result instantly: additions in green, deletions in red, and the exact changed words highlighted inline.
  4. Switch between Split and Unified view, jump between changes with the arrows, or download a .diff.
